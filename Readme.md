# Работа с GPIO на DE2-115 (LEON3 / GRLIB)

Программа на языке C управляет зелёными светодиодами `LEDG` платы **Terasic DE2-115** через контроллер общего ввода-вывода `gpio2` и переключателями SW через контроллер общего ввода-вывода `gpio1`, входящие в состав системы на кристалле на базе процессора **LEON3** (библиотека IP-ядер **GRLIB**).

Цель проекта — показать, как программное обеспечение взаимодействует с периферийными устройствами через запись в регистры, отображённые в адресное пространство памяти (Memory-Mapped I/O).


## Структура проекта
```
├── Makefile          # правила сборки
├── README.md         # этот файл
├── src/
│   └── main.c        # исходный код программы
└── build/            # создаётся автоматически при сборке
    └── gpio_led.elf  # результат компиляции
```

## Работа с проектом
Для сборки выполните в терминале из корня проекта:

```bash
make
```
Для загрузки ПО процессора через grmon запустите grmon:

```bash
grmon -uart /dev/ttyUSB0 -baud 115200
```
Для загрузки ПО в LEON3 в консоли grmon :

```bash
grmon> load build/gpio_led.elf
```
Для запуска ранее загруженного ПО в консоли grmon:

```bash
grmon> run
```

## Требования

### Оборудование

| Компонент | Назначение |
|-----------|-----------|
| Плата Terasic DE2-115 | Целевая платформа (ПЛИС Cyclone IV) |
| ПЛИС с конфигурацией `leon3mp` | Система с ядром LEON3 |
| Кабель питания и кабель конфигурации ПЛИС | Подача питания и загрузка системы |
| Последовательный кабель / переходник | Подключение отладочного интерфейса к ПК |

### Программное обеспечение

| Инструмент | Назначение |
|-----------|-----------|
| Кросс-компилятор `sparc-gaisler-elf-gcc` | Сборка кода под архитектуру SPARC (LEON3) |
| Утилита `make` | Автоматизация сборки |
| Отладчик `grmon` | Загрузка программы и управление системой |

Проверьте, что инструменты доступны в терминале:

```bash
sparc-gaisler-elf-gcc --version
make --version
grmon -version
```
